# Block Travel MVP implementation plan

**Goal:** Implement the approved v1.1 video showcase in the repository root.
**Spec:** ../../block-travel-mvp-development-v1.1.md
**Architecture:** App Router server pages load validated public content. Small client components enhance GET filters and real MP4 links. One shared native dialog owns its media session.
**Constraints:** Node 24, pinned pnpm, Next 16, strict TypeScript, Zod-derived types, CSS Modules, no additional P1 features.

1. Content slice: lock toolchain; write schema/query and filesystem-fixture tests; observe red, implement validation, filtering and stable URL serialization, run Vitest.
2. Page slice: migrate approved tokens, real media, home and catalog; test SSR results, no-JS GET fallback, empty states and responsive layout.
3. Player slice: test delayed loading, close/focus, retries, rapid switching, navigation and stale callbacks; implement unique sessions and deterministic disposal.
4. Delivery slice: build once, run production Playwright, review against v1.1, document publishing/deployment/acceptance, push a feature branch with preserved remote history.

Review focus: IME/history races; traversal and symlinks; last-film archival; fullscreen/PiP cleanup; absent SITE_URL and preview indexing.
